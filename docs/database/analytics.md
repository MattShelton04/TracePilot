## Lifecycle and source truth

The index is a materialized read model. [Snapshot writer](https://github.com/MattShelton04/TracePilot/blob/d95f6d81d8a27f9ee3b18967f00b81d76c25e723/crates/tracepilot-indexer/src/index_db/session_writer.rs#L188) validates that the provider fingerprint still matches, starts a savepoint, deletes old child rows, upserts the session, writes each child table and releases; errors roll back the complete replacement. Format observations delete their rows separately inside the same savepoint. Foreign keys cascade parent deletion. Keys are session-scoped: a tool name, model, run key or event position is not a global identifier.

Schema shape and extraction freshness are independent. [Migration plan](https://github.com/MattShelton04/TracePilot/blob/d95f6d81d8a27f9ee3b18967f00b81d76c25e723/crates/tracepilot-indexer/src/index_db/migrations/plan.rs#L11) adds the tables/columns; [analytics versions](https://github.com/MattShelton04/TracePilot/blob/d95f6d81d8a27f9ee3b18967f00b81d76c25e723/crates/tracepilot-indexer/src/index_db/types.rs#L49) and [source version selection](https://github.com/MattShelton04/TracePilot/blob/d95f6d81d8a27f9ee3b18967f00b81d76c25e723/crates/tracepilot-indexer/src/index_db/session_writer.rs#L381) force snapshot regeneration after semantic changes. Copilot currently uses version 18 and Claude Code uses max(30, 18). [ADR 0013](https://github.com/MattShelton04/TracePilot/blob/d95f6d81d8a27f9ee3b18967f00b81d76c25e723/docs/adr/0013-db-migration-policy.md#L60) requires append-only migrations, transactional backups, staged reader retirement before removal, and explicit treatment for breaking semantic changes. Do not rewrite old migrations to remove a field.

## Provider accounting and consumers

Copilot metrics come from combined shutdown accounting; [shutdown aggregation](https://github.com/MattShelton04/TracePilot/blob/d95f6d81d8a27f9ee3b18967f00b81d76c25e723/crates/tracepilot-core/src/parsing/events/aggregate.rs#L236) preserves the accounting runs. [Claude inclusive input](https://github.com/MattShelton04/TracePilot/blob/d95f6d81d8a27f9ee3b18967f00b81d76c25e723/crates/tracepilot-core/src/provider/claude_code/usage.rs#L67) converts uncached input plus cache reads/writes into canonical inclusive input. Claude calls are deduplicated by message identity; [run accounting](https://github.com/MattShelton04/TracePilot/blob/d95f6d81d8a27f9ee3b18967f00b81d76c25e723/crates/tracepilot-core/src/provider/claude_code/segments.rs#L30) differences cumulative cost snapshots and includes the deduplicated tail. Snapshot USD and estimated tail USD can coexist; SQL retains amounts but not per-row cost basis/coverage.

Three cost units must remain distinct: `cost`/`total_premium_requests` are legacy premium-request units, `total_nano_aiu`/`own_nano_aiu`/`interaction_nano_aiu` are integer nano-AI units, and `cost_usd` is provider USD. [Capability guard](https://github.com/MattShelton04/TracePilot/blob/d95f6d81d8a27f9ee3b18967f00b81d76c25e723/crates/tracepilot-indexer/src/index_db/session_writer/billing.rs#L14) strips unsupported billing from scalar rows and segment JSON. NULL billing means unavailable/unpriced; observed zero is different. `request_count` is API/model requests even though its writer member is called `premium_requests`. Reasoning has an explicit availability sentinel; it must not silently become zero.

Tools use reconstructed calls, including pending invocations and deduplicated lifecycle outcomes: [tool extraction](https://github.com/MattShelton04/TracePilot/blob/d95f6d81d8a27f9ee3b18967f00b81d76c25e723/crates/tracepilot-indexer/src/index_db/session_writer/analytics.rs#L22). Success rate divides known successes by known successes plus failures; pending calls are included in call_count but excluded from that denominator. Mean duration divides summed milliseconds by calls_with_duration, including timed zero-duration calls. Native tool rows are a subset of canonical rows, not extra calls. Agent total_tokens can include descendants; own_nano_aiu is exclusive. Peer-message counts increment both participating peers and must not be interpreted as unique delivery counts.

The SQL fast path crosses [get_analytics / get_tool_analysis IPC](https://github.com/MattShelton04/TracePilot/blob/d95f6d81d8a27f9ee3b18967f00b81d76c25e723/crates/tracepilot-tauri-bindings/src/commands/analytics.rs#L21) and [analytics store](https://github.com/MattShelton04/TracePilot/blob/d95f6d81d8a27f9ee3b18967f00b81d76c25e723/apps/desktop/src/stores/analytics.ts#L106) to the dashboard, model comparison and tool ranking. Agents use [agent IPC](https://github.com/MattShelton04/TracePilot/blob/d95f6d81d8a27f9ee3b18967f00b81d76c25e723/crates/tracepilot-tauri-bindings/src/commands/agents.rs#L255); skills use [skill IPC](https://github.com/MattShelton04/TracePilot/blob/d95f6d81d8a27f9ee3b18967f00b81d76c25e723/crates/tracepilot-tauri-bindings/src/commands/skills/usage.rs#L30). [format diagnostics IPC](https://github.com/MattShelton04/TracePilot/blob/d95f6d81d8a27f9ee3b18967f00b81d76c25e723/crates/tracepilot-tauri-bindings/src/commands/source_diagnostics.rs#L65) feeds Settings diagnostics. Session cache detail [reconstructs its timeline](https://github.com/MattShelton04/TracePilot/blob/d95f6d81d8a27f9ee3b18967f00b81d76c25e723/crates/tracepilot-tauri-bindings/src/commands/session/prompt_cache.rs#L29) from cached events; only older checkpoint-free sessions consult SQL TTL registry.

Exports do not directly read these child rows: [metric export builder](https://github.com/MattShelton04/TracePilot/blob/d95f6d81d8a27f9ee3b18967f00b81d76c25e723/crates/tracepilot-export/src/builder/sections/event_stream.rs#L22) re-extracts source event metrics. Export/session detail presence of a similarly named field does not prove a SQL read. This distinction is why persistence-only fields below are candidates rather than a recommendation to delete their source model fields.

## Table and decoding map

All ordinary analytics queries join `sessions` on child.session_id, applying repository/source/hide-empty as supported by their facade. Date filtering usually uses parent last-active day; agents use run start with session start fallback and skills use invocation time with session start fallback. Their current specialized readers do not accept hide_empty. Every positional SQL SELECT/row.get mapping must move together if query shape changes; SQL column physical order is not the decoder contract.

## Column semantics and dispositions

KEEP means a current SQL consumer or constraint needs the field. DEPRECATE_REMOVE_CANDIDATE identifies stored fields omitted by all production projections reviewed for that table; it is not approval to drop them. No current table is a removal candidate. Confidence is medium for removal candidates because external read-only tooling and future product needs are outside this source trace. Every row inherits the transactional regeneration and migration obligations above.

## Correctness concerns and measurements

1. **Earlier runs disappear when the parent session resumes after the filter window.** [Parent last-active filter](https://github.com/MattShelton04/TracePilot/blob/d95f6d81d8a27f9ee3b18967f00b81d76c25e723/crates/tracepilot-indexer/src/index_db/helpers/filters.rs#L32) is reused by [segment charts](https://github.com/MattShelton04/TracePilot/blob/d95f6d81d8a27f9ee3b18967f00b81d76c25e723/crates/tracepilot-indexer/src/index_db/analytics_queries/dashboard.rs#L109) and [daily models](https://github.com/MattShelton04/TracePilot/blob/d95f6d81d8a27f9ee3b18967f00b81d76c25e723/crates/tracepilot-indexer/src/index_db/analytics_queries/model_usage_by_day.rs#L49). A session with a run in a historical window and updated_at after its upper bound is rejected before segment bounds are applied. Source-backed reachable case, not a reproduced local defect. Measure count/tokens/USD of in-range segments whose parent last-active day is outside the same range, by source; compare session-filtered and segment-filtered totals. A fix must clarify KPI lifetime attribution versus run charts.

2. **Timestamp index evidence is weaker than current query shape.** [Standalone end index](https://github.com/MattShelton04/TracePilot/blob/d95f6d81d8a27f9ee3b18967f00b81d76c25e723/crates/tracepilot-indexer/src/index_db/migrations/sql.rs#L349) has a test for raw end_timestamp >= / <, whereas [actual bounds](https://github.com/MattShelton04/TracePilot/blob/d95f6d81d8a27f9ee3b18967f00b81d76c25e723/crates/tracepilot-indexer/src/index_db/helpers/filters.rs#L85) wrap the indexed column in date(). Agent and skill bounds similarly wrap COALESCE(start,event timestamp, session start). Measure actual EXPLAIN QUERY PLAN with real binds, row counts and distributions before adding indexes; expression/date-normalization or raw UTC bounds require semantic review.

3. **Daily model fallback suppresses a session whenever any segment exists.** [Fallback exclusion](https://github.com/MattShelton04/TracePilot/blob/d95f6d81d8a27f9ee3b18967f00b81d76c25e723/crates/tracepilot-indexer/src/index_db/analytics_queries/model_usage_by_day.rs#L104) does not require segment JSON to be non-NULL/valid. A segment missing model_metrics_json prevents fallback model attribution, while tokens-by-day can still show scalar tokens. Current writer serialization uses .ok(); measure segment JSON NULL counts and parse validity, plus sessions whose lifetime models exist but all segments lack JSON. Do not silently replace source accounting runs with lifetime totals.

4. **Stored billing precision and provenance differ from display precision.** Several Copilot u64 counters are cast with as i64 in [analytics extraction](https://github.com/MattShelton04/TracePilot/blob/d95f6d81d8a27f9ee3b18967f00b81d76c25e723/crates/tracepilot-indexer/src/index_db/session_writer/analytics.rs#L132) whereas agents/cache windows use saturation. Normal telemetry is expected to fit; no observed overflow is asserted. Measure negative persisted billing/token values without exposing content. USD basis/partiality from provider run objects is not persisted in scalar child rows; model distribution only infers partial USD from contributing NULL rows. Review whether DTOs need snapshot-versus-estimate coverage before changing schema.

5. **Cache source/confidence is not persisted.** The writer stores checkpoint-predicted and recorded-call windows but the cross-session DTO still names its session count sessions_with_predicted. [Admission rule](https://github.com/MattShelton04/TracePilot/blob/d95f6d81d8a27f9ee3b18967f00b81d76c25e723/crates/tracepilot-indexer/src/index_db/session_writer/prompt_cache.rs#L25) admits Claude windows; [Aggregation label](https://github.com/MattShelton04/TracePilot/blob/d95f6d81d8a27f9ee3b18967f00b81d76c25e723/crates/tracepilot-indexer/src/index_db/analytics_queries/prompt_cache.rs#L77) counts both. A source filter prevents unintended source mixing when selected, but the all-source view has no confidence split. Measure windows by parent source/outcome; review label or store confidence/source if the product needs cross-source interpretation. TTL registry remains checkpoint-only to avoid teaching Copilot estimates from Claude recorded tiers.

6. **Measure removal candidates before migration.** The 20 persistence-only columns above include duration boundaries, dispatch configuration, cache expiry details and correlation/plugin metadata. Collect only aggregate NULL/non-NULL coverage, character/byte-length distributions and estimated bytes per column by source; do not print text values, paths, names, IDs or payloads. Compare row-storage reduction with indexes/JSON/FTS footprint. Keep source fields used to derive active metrics. Reader deprecation, external-consumer review, analytics version refresh and a later backed-up drop are separate steps.

7. **Scale of Rust aggregation is unmeasured.** Agents/skills load every filtered invocation before Rust grouping and percentile/path calculations; recent detail truncation happens after loading. Measure rows returned and query/aggregation/IPC time for all-history and bounded windows, by source. The comment claiming only a few hundred skill invocations is not a storage limit. Preserve NULL estimates and per-run token hierarchy semantics when optimizing.
