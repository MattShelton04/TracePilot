# TracePilot desktop audit: source inventory

This is a **source-discovered inventory, not a claim of live verification**. It was compiled on 2026-09-12 from the router, application bootstrap, window commands, views, component templates, feature defaults, and their composables. The [per-surface tracker](surface-coverage.md) reconciles all 124 rows with actual Tauri observations, evidence, fixes, and specific unverified remainder. A page visit does not cover its nested surfaces or conditional states.

Source paths below are relative to the repository root. Each `SRC-*` ID identifies a stable audit surface. All applicable rows require 1440×960 CSS-pixel coverage first, then 960×640 and 2560×1440. Layout checks must include long content, both themes, collapsed/expanded navigation, supported UI scaling, and preserved context. Native viewer windows have their own dimensions, documented below.
