# Copilot CLI Version Analysis Reports

This folder holds timestamped reports generated by the `tracepilot versions report` CLI command. Reports predating the 2026-05-01 documentation cleanup were removed; generate a fresh report when you need current coverage data.

The May 2026 v1.0.40 refresh plan recorded a pre-implementation baseline of
36/39 persisted event types handled and an approximately 755,000-line local
JSONL corpus. The [post-implementation report](2026-05-04-v1.0.40-report.md)
records 39/39 coverage and the schema/corpus findings. Both figures are
historical observations, not a current compatibility guarantee.

The [1.0.83 alignment report](2026-09-12-v1.0.83-alignment.md) also records the
recovered 1.0.71 baseline, compatibility fixes, live validation and useful future
UI opportunities.

## Naming Convention

Reports follow the format: `{date}-v{latest_version}-{label}.md`

- **date:** `YYYY-MM-DD` of generation
- **latest_version:** The newest installed Copilot CLI version at time of generation
- **label:** A short descriptor (`baseline`, `post-implementation`, `quarterly-review`, etc.)

## How to Generate a New Report

```bash
# Generate with a timestamped name
pnpm cli versions report --output "docs/reports/versions/$(date +%Y-%m-%d)-v{VERSION}-{label}.md"

# Focus a report on a baseline → target Copilot CLI schema window
pnpm cli versions report --from 1.0.24 --to 1.0.40 --output "docs/reports/versions/$(date +%Y-%m-%d)-v1.0.40-report.md"

# Or on Windows PowerShell:
pnpm cli versions report --output "docs/reports/versions/$(Get-Date -Format yyyy-MM-dd)-v1.0.7-label.md"
```

## When to Generate

- **After adding new event type support** — to document the coverage improvement
- **After a new Copilot CLI version is installed** — to detect schema changes
- **Periodically** — to track the evolving gap as Copilot CLI evolves

## Other Useful Commands

```bash
# Quick coverage check (no full report)
pnpm cli versions coverage

# List installed versions
pnpm cli versions list

# Diff specific versions
pnpm cli versions diff 1.0.5 1.0.7

# Find sessions with a specific event type
pnpm cli versions examples -e session.truncation

# Generate a focused markdown report with empirical field observations
pnpm cli versions report --from 1.0.24 --to 1.0.40 --output docs\reports\versions\2026-05-04-v1.0.40-report.md
```
