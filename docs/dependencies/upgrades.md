## Risk rubric

Scores are ordinal **likelihood × impact**, out of 25; they are not probabilities. Likelihood: 1 narrow compatible change with strong relevant validation; 2 localized concerns; 3 meaningful untested/cross-package change; 4 documented breaking/native/protocol migration; 5 demonstrated incompatibility or fundamental unresolved behavior. Impact: 1 local tooling; 2 isolated development/test feature; 3 user capability; 4 startup/core workflow/platform; 5 data integrity, security boundary, ownership or distribution. Unknowns remain explicit. Effort and reversibility are separate.

The post-validation values below apply only when the corresponding checks in [measurements](measurements.md) pass. Other platforms, signed updates and a paid provider session remain outside that evidence.

## Retained groups and bounded follow-ups

- **SDK/Specta:** preserve github-copilot-sdk =1.0.14 with defaults disabled and COPILOT_SKIP_CLI_DOWNLOAD=1. Preserve the exact Specta compatibility set; generated IPC and protocol/session ownership are product contracts. See [Rust](rust.md). A coordinated trial must cover generation, CLI discovery, observer attach/disconnect and preference guards. Provider-backed execution was not inferred from protocol-peer tests.
- **Tauri:** core, CLI, API, plugins and capability configuration form a compatibility group, but their versions need not be numerically identical. Current range compatibility is represented in the graph. A framework refresh needs Windows packaging and Linux WebKit/GTK tests before claiming to fix legacy platform advisories.
- **Reqwest/Zip duplicates:** a direct reqwest 0.13 or zip update does not remove the SDK's 0.12/2.x paths. Reqwest 0.13 changes feature/TLS defaults; moving a declaration alone is not deduplication. Preserve explicit rustls client selection and document the native-TLS path still introduced by the SDK.
- **Vue build stack:** retain Vite 6/plugin-vue 5/vue-tsc 2/TypeScript 5 outside the targeted security changes. Major compiler/bundler migrations require their own compatibility and bundle trial. Preserve the postcss 8.5.23 override until every parent independently resolves the patched line; do not remove a security pin by inference.
- **Lucide:** retain lucide-vue-next 1.0.0 for this batch; @lucide/vue 1.48.0 is the separately scoped rename target. Its many template imports require an icon mapping and visual checks. No direct advisory justified combining that rename with the test-runner security migration.
- **Node:** the installed and measured Node is 22.19.0; the declared floor now matches jsdom's Node 22.12 requirement. A Node 22.23.3 patch trial is separate so package changes and runtime changes are not confounded. Recheck the current LTS security release before that trial.

Full per-package decisions and primary sources are in the two matrices linked above. [Security](security.md) distinguishes patched findings from parent-bound maintenance/unsoundness and license-policy findings. [Roadmap](roadmap.md) gives acceptance tests and rollback for deferred work.
