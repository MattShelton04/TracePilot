### Fixed

- **Export errors** — A failed export now says why (for example, a file that can't be written) instead of "Action failed". Raw Zip is offered only for Copilot sessions, with a hint for Claude Code sessions, and a Raw Zip selection falls back to JSON when you pick a Claude Code session.
- **Search indexing banner** — Search now shows an indexing pass that started before you opened it, so partial results are flagged and "Build Search Index" no longer fails with "Indexing is already in progress".
