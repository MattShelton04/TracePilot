### Fixed

- **Command palette** — Ctrl+K finds sessions by name, repository, folder, branch or ID prefix, and lists them
  above conversation matches. It no longer says "No results" for a session's exact title.
- **Alert center shortcut** — Ctrl+Shift+A and its row in the `?` shortcut help appear only while Alerts are on.
- **Settings path fields** — The Copilot home, TracePilot data directory and Claude Code folder fields widen to fit
  long paths and show the full path on hover, and the index database path wraps instead of squeezing its label.
