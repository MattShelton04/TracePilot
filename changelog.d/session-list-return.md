### Added

- **Open search results from the keyboard** — Ctrl+Enter (⌘Enter on macOS) opens the highlighted Search result at its turn; Enter still expands it.

### Changed

- **Filtered session count** — While a search or filter narrows the session list, the toolbar shows "12 of 340 sessions" with a Clear action next to it.

### Fixed

- **Back to where you were** — Going back from a session returns the session list and Search results to the same scroll position instead of the top.
