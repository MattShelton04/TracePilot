02 Conversation

Three agents. One turn.

Every prompt, reply and tool call, in order, with the agent that made it.

Parallel subagents fan out in their own colours, each with its model, token count and runtime.

Follow-ups and read-backs land where they happened. You can see who finished first.

Tool calls open into rich renderers: diffs, test output, file views.

Illustration: the Conversation tab. Copilot launches three subagents in parallel (code review, Playwright coverage, Safari support check), sends one follow-up, reads each result back, and then applies a fix shown as a diff.

08 Private by design

Your sessions never leave your machine.

TracePilot reads ~/.copilot/session-state directly and keeps its index in a local SQLite file. Search runs against that file, not a server. Open source under GPL-3.0, so you can check.

Run it from the repository

Build from source

Read the code before you run it, skip the unsigned installer, or work on TracePilot itself.

  1. Install the toolchain

    • Ruststable, from rustup.rs
    • Node.js 2222.12 or a later 22.x, from nodejs.org
    • pnpm 10the repository pins the exact version
    npm install -g pnpm@10

    Windows 10 or 11

    Microsoft C++ Build Tools with Desktop development with C++; the rustup installer offers to add them. WebView2 is already part of Windows.

    macOS 12+ on Apple Silicon

    The Xcode Command Line Tools.

    xcode-select --install

  2. Clone the repository

    git clone https://github.com/MattShelton04/TracePilot.git
cd TracePilot

  3. Install and launch

    pnpm start

    Installs the workspace dependencies, compiles the Rust backend and opens the desktop app.

  4. What to expect

    The first build takes several minutes; later starts are much quicker. When the TracePilot window opens, setup finds your Copilot CLI sessions and indexes them. The terminal also prints a localhost address: ignore it, because a browser tab can't reach the app's backend.
