# Dependency graph capture

From the repository root, capture a locked input set with an **already installed** pnpm CLI:

```powershell
python scripts/dependencies/capture_inputs.py final --pnpm-cli .agent/dependency-audit/tools/pnpm/package/bin/pnpm.cjs
python scripts/dependencies/generate_graph.py final
python scripts/dependencies/test_graph.py --graph .agent/dependency-audit/final/graph.json
```

The capture command requires Python 3.11+, Cargo, Node, and an installed workspace with the root's declared `yaml` package (currently 2.9.0); run the normal frozen install before capture. It needs no Python package installation. `--pnpm-cli` points at a pre-existing pnpm `.cjs` file; it never provisions pnpm. The script runs `cargo metadata --locked --offline` for all-features, default, Windows, Linux, and macOS resolver views and `pnpm list -r --depth Infinity --json`. It parses YAML through the installed root Node package with structured subprocess arguments, reads current manifests and lockfiles, verifies their SHA-256 hashes did not change, probes package path existence, and fetches exact locked npm metadata for uncached versions. It does **not** run install, update, audit, build, or tests. When network access is unavailable, pass `--offline-registry`: uncached packages are explicitly recorded as metadata errors. `--pnpm-list-file <path>` can replace `--pnpm-cli` when a list JSON capture already exists; package paths are still checked at capture time. `--registry-cache <path>` selects a cache of exact locked version metadata.

The capture writes ignored inputs and a UTC/SHA-256 receipt under `.agent/dependency-audit/<phase>/`; the graph generator writes `graph.json` in that same ignored directory. Generated graphs and raw measurements are local audit artifacts, not tracked source. Retain readable findings and decisions in `docs/dependencies/`. Valid phases are `baseline` and `final`: capture baseline at the revision being compared before dependency edits, then capture the changed checkout as final. A fresh checkout does not contain historical captures.

Graph schema 3 preserves Cargo metadata source or a repository-relative workspace path and the matching lock checksum. pnpm snapshots preserve the lock resolution/integrity and exact registry metadata URL; the isolated npm package preserves its lock resolved URL/integrity. Every node carries a bounded `update_disposition`: direct packages point to the reviewed version matrix, transitive packages are retained through their introducing direct parents pending targeted validation, and scanner findings point to the security record. A transitive leaf's latest stable version is explicitly **not individually verified** by this graph. A future Cargo same-name/version collision from distinct sources fails generation until its graph identity is disambiguated.

Security scanner output is a separate optional input. Copy the matching phase's RustSec JSON to `rustsec.stdout`, cargo-deny JSONL to `cargo-deny.stderr`, full and production pnpm audit JSON to `pnpm-audit-full.stdout` and `pnpm-audit-prod.stdout`, and isolated npm audit JSON to `npm-audit.stdout` before graph generation. Missing scanner files are marked **unscanned**, not clean. The graph records resolver and lock edges; it does not claim a human source review for every transitive package. Windows desktop path classes distinguish ordinary, build/proc-macro, test, and optional-edge paths and can overlap when multiple paths reach one package.

`python scripts/dependencies/test_graph.py` runs the synthetic resolver tests without requiring audit captures; the capture-dependent class is explicitly skipped. Fixtures exercise multiple peer contexts, Cargo source-collision rejection, source-input coverage, and presence probing. Pass `--graph PATH` to also check a generated graph's lock populations, source/integrity identity, direct mappings, bidirectional edges, alias resolution, root scopes, private-path redaction, and every node's explicit update/security disposition. Repeat `--graph` to validate both baseline and final. An explicitly requested missing graph is an error. Neither mode launches the app or builds dependencies.

The generator owns local graph JSON formatting; `test_graph.py` checks its structural invariants. No formatter exception is needed for generated evidence because `.agent/` is already ignored.
